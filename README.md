# Bucket for iPhone: releases

Builds of Bucket for sideloading with [SideStore](https://sidestore.io). The source code lives in a separate private repository. This repo only hosts the `.ipa` files (under Releases) and the SideStore source.

**Add the source in SideStore** → Sources → **+**:

```
https://raw.githubusercontent.com/jasfertoh/bucket-ios-releases/main/apps.json
```

Then install Bucket from it. New versions appear as updates in My Apps.
